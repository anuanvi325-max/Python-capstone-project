# 📸 BookVault Screenshots Directory

This folder is designated for UI screenshots referenced in the main `README.md`.

### Recommended Screenshots:
1. **`landing-page.png`**: Hero section and landing page.
2. **`student-dashboard.png`**: Student view with stats, available books catalog, and activity log.
3. **`librarian-dashboard.png`**: Librarian operational view with statistics, issued books, and audit stream.
4. **`book-details.png`**: Book detail page displaying author, ISBN, and availability.
5. **`pending-fines.png`**: Overdue tracking and calculated fines ledger.
6. **`add-book.png`**: Book entry form with validation.
7. **`login-signup.png`**: The flip-card 3D authentication screen.

### How to Add Your Screenshots:
1. Take a screenshot of the respective view in your browser (recommended resolution: 1920x1080 or cropped browser window).
2. Save or copy the image into this `docs/screenshots/` directory using the filenames listed above.
3. Commit and push the images to GitHub. The images will automatically render in the `README.md`!
